# 选题策划阶段

- **目标**　形成可交付给内容分析阶段的短视频选题简报。
- **允许输入**　默认根据当前用户输入、已确认的阶段输入和用户明确提供的材料开展选题。
- **普通选题**　用户只给出主题或一般选题要求，当前任务也没有明确的画布或文件依赖时，直接提出候选或澄清必要条件。已有素材未知就标为待确认。此时跳过 `drama_context`、`drama_query` 和工作区文件检索。
- **点名节点**　已知节点 ID 时用 `drama_query` 按 `id` 读取。成功后直接依据指定节点策划。只有用户也要求检索其他素材，或已确认的阶段输入还指定了其他素材时，才扩大到其他节点。
- **画布检索与盘点**　用户明确要求利用、检索或盘点画布素材，或已确认的阶段输入指定了画布材料时，可用 `drama_query`。没有 ID 时先按主题关键词或已知类型筛选，按需扩大范围并区分相关与无关素材。任务只要求盘点画布时，跳过工作区文件和生成任务检索，缺少素材就说明缺口。只在画布是必需输入且查询遇到连接问题时处理连接状态。
- **必需产出**　使用 `drama_save_artifact` 保存 Markdown 选题简报，记录候选、选择依据、选题方向、可用素材与待确认项。
- **完成条件**　先请用户确认选题，再由用户在 Studio 确认阶段交接。把事实、分析判断和待核实假设写清楚。
