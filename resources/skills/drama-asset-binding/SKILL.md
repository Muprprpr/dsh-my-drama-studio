# 素材抽卡与绑定

## 目标

给每个镜头建立可回查的素材映射和缺口清单。

## 输入

已确认的分镜、参考素材、项目资产和用户指定的引用。

## 工作步骤

1. 按镜号列出角色、场景、道具、动作参考和声音需求，标明每个素材在生成中要承担的职责。
2. 查询已有候选，核对角色造型、视角、场景布局和清晰度等是否与分镜一致。跨镜复用时检查服装、道具状态和光线。
3. 记录选中的实际图像、视频或音频节点、项目引用和使用镜号。将候选、待确认与已选状态分开。
4. 标明素材缺口及对部署的影响，由用户决定补齐方式。

## 输出与检查

交付镜号到素材引用的映射表，逐项标明媒体类型、职责、选择依据和缺口。确认引用的媒体实际存在且可读。

## 禁止事项

不得把空路径、未取得的候选或未生成的结果写成可用资产。
