# 短视频选题策划

汇总用户已给出的目标、受众、平台、风格与制作约束。提出少量可区分的候选选题，逐项写明受众为什么会点开、视频能交付什么、已有素材、拍摄可行性和待核实事项。

按用户的项目目标比较候选。记录用户确认的选题、核心看点、叙事方向、需要查证的依据、可用素材与限制。用户还未选择时，标出候选和推荐理由，保留待确认状态。

将选题简报保存为 Markdown 阶段产物。简报应让内容分析阶段明确要分析的问题及其依据。
