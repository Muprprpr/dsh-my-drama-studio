# 视频节点部署

## 目标

为各个可部署镜头创建可供用户预检的 Canvas 视频草稿。

## 输入

已确认的分镜、素材映射、真实存在的媒体和当前可用模型预设。

## 工作步骤

1. 按镜号决定生成方式和参数。纯文本用 T2V，首帧生视频用 I2V，并按模型能力选用尾帧。多媒体参考用 R2V，源视频编辑用 V2V。仅使用模型支持的时长、分辨率、画幅和参考输入。
2. 将完整生成提示词直接写入该视频节点自己的提示词字段。包含对白、表演、动作、场景、素材职责、声音和首尾气口。所有要求直接写明。
3. 按模型所需连接真实图片、视频和音频。引用顺序与所连接的实际媒体一致。需要批量部署时保留各镜号、节点 ID 和参数的对应关系。
4. 新建、复制、修订、连线及交付前回读每个节点。确认提示词非空且完整、上游没有文本类节点、`textList` 为空或不存在，`mixedListOrder` 和提示词引用仅对应已连接媒体。发现不一致时先修复再报告完成。

## 输出与检查

交付已验证的视频草稿节点和部署清单，列明镜号、节点 ID、模式、模型、媒体职责及无法部署的原因。

## 禁止事项

禁止把任何文本、脚本或说明节点作为视频生成输入。必须保留的说明应断开。清理旧连线时保留视频节点当前完整提示词、用户编辑和已有成片。禁止触发生成。
