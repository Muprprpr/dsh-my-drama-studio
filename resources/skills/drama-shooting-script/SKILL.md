# 拍摄脚本制作

## 目标

把故事写成可供表演、拍摄及后续拆镜的脚本。

## 输入

已确认的内容分析与用户补充的剧情、对白、时长及制作要求。

## 工作步骤

1. 按地点、时间或剧情任务划分场景，分配稳定的场景编号，并标注场景如何衔接。
2. 按发生顺序写可观察的动作、说话人及对白。用表演和声音表达需要观众察觉的情绪与信息。
3. 核对场内人物、道具和空间条件是否足以完成动作。估算段落时长，为对白和反应保留时间。
4. 标记需用户确认的取舍，尤其是改动剧情、对白和顺序的建议。

## 输出与检查

交付含场景号、地点和时段、出场人物、动作、对白及预计时长的拍摄脚本。检查每场都有可执行的动作和明确的剧情推进。

## 禁止事项

不得擅改已批准的情节、对白或创作限制。
