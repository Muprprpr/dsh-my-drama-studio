# 内容分析

## 目标

把源材料转成后续拍摄脚本可以引用的创作依据。

## 输入

用户提供的原文、素材及制作要求。区分原文事实、用户已确认决定和待确认事项。

## 工作步骤

1. 按故事起因、发展、转折和结果列出关键事件。标明它们在源材料中对应的段落或时间点。
2. 为主要人物记录设定、目标、关系和行动动机，指出推动情节变化的冲突。
3. 整理场景的地点、时间和叙事功能，记录篇幅、受众、风格及制作限制。
4. 将事实无法支持的判断写成待确认项。

## 输出与检查

交付内容分析稿，包含剧情脉络、人物关系、场景表、核心冲突、需保留内容和创作约束。逐项核对关键判断能追溯到源材料或用户决定。

## 禁止事项

不得补写源材料缺失的剧情，也不得把推测登记为已确认设定。
