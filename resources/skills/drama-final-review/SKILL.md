# 成片验收

## 目标

逐镜评审实际成片，并将需要重做的部分定位到镜号和时间点。

## 输入

已交接的可播放视频、原分镜和已确认的创作与制作约束。

## 工作步骤

1. 核对交付片段、镜号、版本和时长。逐项检查丢帧、画面瑕疵、角色与道具一致性及场景连贯。
2. 对照约定检查语音、口型、音效、环境声及各镜声音衔接。
3. 查看动作和剪辑的起止点，核对叙事信息是否齐全，首尾是否有足够的可剪空间。
4. 记录问题的位置、证据、影响及建议动作。无法获取的音画信息标为待核。

## 输出与检查

交付验收报告，按镜号记录结果版本、已验证事项、问题证据及返工清单。验收建议提交用户决定。

## 禁止事项

不得将不可播放、未检查或证据不足的镜头写为通过。不得自行确认最终验收或将正式工作流标为 Approved。
