# 分镜制作

## 目标

将拍摄脚本拆成可逐镜头制作的分镜。

## 输入

已确认的拍摄脚本、视觉约束及用户指定的参考。

## 工作步骤

1. 按动作、对白和信息揭示的先后拆镜，为每个镜头分配稳定编号及所属场景。
2. 写明景别、视角、主体构图、角色动作、运镜起止和声音。保持人物朝向、空间位置及道具状态连续。
3. 给出每镜时长和剪辑衔接。检查说话、动作、反应及首尾停顿的时间是否足够。
4. 标出每镜需要的角色、场景和道具参考，以及留待素材阶段解决的缺口。

## 输出与检查

交付逐镜分镜表，至少含场景号、镜号、时长、画面与运镜、动作与对白、声音、衔接及素材需求。核对镜头能完整覆盖已确认脚本。

需要统一景别用语时，可查阅本 Skill 目录中的 `references/shot-sizes.md`。分镜表可参考 `templates/storyboard.md`。如有结构化镜头数据，可查看 `scripts/check.js` 中的基础字段校验示例。

## 禁止事项

不得将未经确认的剧情新增、场序调整或对白改写纳入正式分镜。
