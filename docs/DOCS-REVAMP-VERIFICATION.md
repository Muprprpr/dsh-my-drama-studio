## 实际操作证据

Windows 候选包构建脚本核验打包的归档内容、随包资源、Go 构建元数据和三份核心文件哈希。隔离 Home 用 Desktop 自带 CLI 执行 `plugin --profile web add`，核对安装文件三个哈希与候选报告一致，再启动 DSH Web。真实浏览器出现 **Drama** 和 **Settings → Drama Studio**。脚本创建专用示例工作区与会话，浏览器选择并操作这些会话。
